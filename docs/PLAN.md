# MIDI Generator — план разработки

> Веб-генератор MIDI на чистых алгоритмах (без ИИ), с гибкими настройками, live-превью, редактором piano roll в стиле FL Studio и экспортом `.mid`.
> Документ — рабочий: отмечайте выполненные пункты `[x]` по ходу работы.

---

## 0. Контекст и ключевые решения

**Отправная точка:** в `midi-generator/` лежит только scaffold — React 19 + TypeScript 6 + Vite 8 + React Compiler + oxlint.

**Требования:**
- Одна страница, без регистрации и бэкенда. История генераций — позже (отдельная страница/панель), но модель данных сразу делаем сериализуемой.
- Дизайн современный, но в первую очередь функциональный.
- Генерация только алгоритмическая, воспроизводимая по seed.

**Принятые решения:**

| Вопрос | Решение |
|---|---|
| Режим генерации | На выбор: **одна партия** (выбранный тип) или **мультитрек** с выбором партий и инструментов |
| Звук превью | На выбор: **встроенный синтезатор** или **1 из 3 бесплатных сэмпл-паков**; сэмплы грузятся только по необходимости |
| Язык интерфейса | **RU / EN / DE** через i18n + JSON-файлы |
| Длина паттерна | **1–32 такта**, по умолчанию 8 |
| Аудио-движок | Собственный на Web Audio API (lookahead-планировщик), без Tone.js |
| Редактор | Canvas piano roll с undo/redo |

**Стек и зависимости:**

| Пакет | Назначение |
|---|---|
| `@tonejs/midi` | Запись (позже — чтение) `.mid`, type 1, PPQ 480 |
| `i18next`, `react-i18next`, `i18next-browser-languagedetector` | Локализация |
| `zustand` + `zundo` | Состояние + undo/redo |
| `smplr` | Сэмпл-инструменты (Soundfont, DrumMachine), только через динамический `import()` |
| `fflate` | ZIP-архив при экспорте треков по отдельности |
| `vitest` (dev) | Тесты ядра генерации и экспорта |

Стили — обычный CSS + CSS-переменные (CSS Modules), без UI-фреймворков. Тёмная тема по умолчанию + светлая.
