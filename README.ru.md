# MIDI Generator

[English](README.md) · **Русский**

Веб-приложение, которое пишет MIDI-паттерны с помощью музыкальных алгоритмов, а не ИИ. Выберите
жанр, настроение, тональность и партии. Затем сгенерируйте паттерн, послушайте его и
отредактируйте в пианоролле в стиле FL Studio. Готовые `.mid` файлы можно экспортировать в вашу
DAW. Всё работает в браузере: сервера и регистрации нет.

![MIDI Generator: панель настроек, список треков и пианоролл](docs/screenshot.png)

## Возможности

- **Генерация.** Одна партия или целая аранжировка: ударные, бас, аккорды, мелодия, арпеджио,
  пэд и рифф. Все партии строятся на одной общей последовательности аккордов. Одни и те же
  настройки и сид всегда дают одинаковый результат, а любую партию можно перегенерировать
  отдельно.
- **Стили.**
  - 15 жанров: поп, хип-хоп, лоу-фай, хаус, техно, драм-н-бейс, рок, метал, дэт-метал,
    трэш-метал, дум-метал, стоунер-рок, джаз, фанк и эмбиент.
  - 9 настроений и 13 ладов.
  - Размеры 4/4, 3/4 и 6/8, от 1 до 32 тактов.
  - Настройки свинга, сложности и «очеловечивания».
- **Воспроизведение.** Встроенный синтезатор и драм-кит на Web Audio или один из трёх
  [сэмпл-паков](#сэмпл-паки). Есть зацикливание фрагмента, метроном и смена темпа на лету.
  Для каждого трека есть mute, solo и громкость, а поверх них общая громкость.
- **Пианоролл.**
  - Инструменты рисования, выделения и удаления.
  - Перемещение и растягивание нот с привязкой к сетке от 1/4 до 1/32, включая триоли.
  - Выделение рамкой и дорожка velocity.
  - Ноты других треков бледно видны на фоне.
  - Масштабирование, отмена и повтор.
  - Правки слышны сразу, даже во время воспроизведения.
- **Экспорт.**
  - Один многодорожечный `.mid`: формат 1, PPQ 480, ударные на 10-м канале.
  - Отдельные треки или ZIP со всеми треками.
  - В браузерах на Chromium трек можно перетащить прямо в DAW.
- **Интерфейс.** Русский, английский и немецкий языки. Тёмная и светлая темы. Работает вплоть до
  ширины планшета.

## Запуск

Нужен [Node.js](https://nodejs.org/) версии 20.19, 22.12 или новее. Приложение лежит в папке
`midi-generator/`.

```bash
git clone https://github.com/loki554/MIDI-Generator.git
cd MIDI-Generator/midi-generator
npm install
npm run dev
```

Затем откройте адрес, который выведет Vite, обычно это <http://localhost:5173>.

| Команда | Что делает |
|---|---|
| `npm run dev` | Запускает сервер разработки |
| `npm run build` | Проверяет типы и собирает production-версию в `dist/` |
| `npm run preview` | Раздаёт production-сборку |
| `npm run lint` | Запускает oxlint |
| `npm run test` | Один раз прогоняет юнит-тесты (`test:watch` оставляет их запущенными) |
| `npm run check` | Линтер, тесты и сборка разом |

Сборка — это статический сайт, содержимое `dist/` можно выложить на любой статический хостинг.

## Горячие клавиши

| Клавиши | Действие |
|---|---|
| Ctrl/⌘ + Enter | Сгенерировать |
| Пробел | Воспроизведение / стоп |
| Ctrl/⌘ + Z, Ctrl/⌘ + Y (или Shift + Z) | Отменить, повторить |
| P / E / D | Рисование, выделение или удаление |
| Delete, Ctrl + A / C / X / V / D | Удалить, выделить всё, копировать, вырезать, вставить у курсора, дублировать |
| ↑ ↓ (с Shift — на октаву), ← → | Транспонировать, сдвинуть на шаг сетки |
| Alt при перетаскивании | Двигать или растягивать без привязки |
| Ctrl + колесо, Alt + колесо | Масштаб по времени, масштаб по высоте |

## Сэмпл-паки

Встроенный синтезатор генерирует звук прямо в браузере и ничего не скачивает. Три сэмпл-пака
необязательны, их выбирают в меню звука в шапке. В каждом паке General MIDI саундфонт отвечает
за мелодические треки, а сэмплированная драм-машина за ударные:

| Пак | Мелодические треки | Лицензия | Ударные | Лицензия |
|---|---|---|---|---|
| GM Classic | FluidR3_GM, автор Frank Wen | CC BY 3.0 | LinnDrum LM-2 | Общественное достояние |
| GM Rich | Musyng Kite | CC BY-SA 3.0 | Casio RZ-1 | Общественное достояние |
| Electronic | FatBoy | CC BY-SA 3.0 | Roland TR-808 | Общественное достояние |

Как устроены паки:

- **Источники.** Саундфонты берутся из
  [gleitz/midi-js-soundfonts](https://github.com/gleitz/midi-js-soundfonts), драм-машины из
  [smpldsnds/drum-machines](https://github.com/smpldsnds/drum-machines). Оба раздаются через
  GitHub Pages и проигрываются библиотекой [smplr](https://github.com/danigb/smplr). Сэмплы не
  хранятся в этом репозитории и воспроизводятся без изменений.
- **Загрузка по требованию.** Пока пак не выбран, ничего не скачивается. После выбора
  загружаются только инструменты, которые есть в текущем проекте.
- **Запасной вариант.** Пока инструмент не загрузился или если загрузка не удалась (например,
  без интернета или при недоступности GitHub Pages), трек играет на встроенном синтезаторе.
- **Ударные.** Ноты GM-ударных сопоставлены со звуками драм-машины. Ноты, которых в машине нет,
  например тарелку china, играет синтезаторный кит.
- **Громкость.** Каждому паку задано постоянное усиление, подобранное замером так, чтобы он
  звучал примерно так же громко, как встроенный синтезатор.
- **Экспортированные файлы.** В `.mid` попадают только ноты и настройки, звук из паков туда
  никогда не попадает.

Авторы и лицензии также указаны в самом приложении, в меню ⓘ в шапке.

## Как это работает

В генераторе нет машинного обучения и сетевых запросов. Набором музыкальных правил управляет
генератор случайных чисел с сидом:

1. Лад и последовательность аккордов выбираются по взвешенным таблицам для жанра и настроения.
2. Генератор каждой партии пишет ноты поверх этой общей гармонии. Ударные берут паттерны,
   заданные для жанра. Бас играет ноты аккорда в манере, подходящей жанру, например 808, фанк
   или «шагающий» бас. Мелодия ставит ноты аккорда на сильные доли и заканчивается на
   устойчивом звуке.
3. «Очеловечивание» вносит небольшие отклонения во время и силу нот, а свинг сдвигает слабые
   доли.

Генератор случайных чисел работает от сида, поэтому те же сид и настройки воспроизводят
точно такой же паттерн.

## Стек

React 19, TypeScript, Vite, zustand + zundo, i18next, @tonejs/midi, smplr, fflate,
lucide-react, Vitest и oxlint.

```
midi-generator/src/
  core/        чистая логика: модель данных, генератор случайных чисел, теория музыки,
               пресеты жанров и настроений, генераторы партий, экспорт MIDI и ZIP
  audio/       движок Web Audio, планировщик, синтезаторные голоса, загрузчик сэмпл-паков
  store/       сторы zustand (настройки, проект с историей отмен, UI, воспроизведение, сэмплы)
  i18n/        настройка i18next и locales/{ru,en,de}.json
  components/  интерфейс на React (настройки, треки, транспорт, пианоролл, экспорт)
docs/PLAN.md   план разработки
```
